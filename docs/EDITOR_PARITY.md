# Editor parity baseline

Original reflects the supplied CFG and `EditorReadMe.txt`. VRV reflects local implementation files where available. Control names describe the reference and do not establish identical behavior on 2.0.185.

| Area | Reference | BZ_MAP_MAG |
|---|---|---|
| Height | Original `bzeditor_height.cfg`, VRV `vrv_editor_keys.cfg` | IMPLEMENTED Raise, Lower, Blend, Paint, Spray and Pick. Four brush shapes, six widths and four pressures with buttons and VRV shortcuts. Brush response and fill parity remain open. |
| Navigation | Original camera and schematic views, VRV overhead reference screenshots | IMPLEMENTED 3D-first resizable workspace with height controls and 2D map, solid/wireframe, overhead/orbit, pan, zoom, focus, synchronized cursors and a dedicated fly mode (F, W/S/A/D, Q/E, right-drag look). |
| Terrain colors/textures | Original color and tile tools, VRV selectable mirrored layers | IMPLEMENTED native RGB and tile slot painting with undo, saved project state and TER export. Alpha and draw masks pass through. Texture repeat is approximate. |
| Water/Sky/Fog | `bzeditor_water.cfg`, environment CFG, VRV separate lighting/fog page | IMPLEMENTED multi-layer water preview plus coverage painting and elevation editing for matching WAT v5 maps. Coverage strokes (Shift erases), layer elevation and 8-layer selection share undo, BZMAG save and the re-import-verified in-place WAT export; both views show the effective layers, and a water-only export carries full in-game MISSION / RUN acceptance. Sky/fog tools stay documented as pending (2.0.185 exposes them only as runtime console commands and the `.SKY` container has no reference codec — see ENGINE_LIMITATIONS). |
| Save/Undo | Engine save, VRV `EditorSaveHost.cpp` and `EditorTerrain.h` rolling terrain autosaves | IMPLEMENTED fixed source revisions, brush and bake undo/redo, project snapshots, transactional native export and a transactional autosave store outside the map folder: slots are written to a per-project identity folder under the configurable autosave root (default `user://autosaves`), verified by a full project re-open, atomically published and only then pruned to a rolling three. A Recover dialog lists the slots, and a never-written-into state of the source folder is asserted by the suite. Project merge pending. |
| Mirror | `EditorTerrain.h`, `TerrainShape.h`, `EditorBrush.h`, `ObjectSymmetry.h` | IMPLEMENTED directional X/Z heightfield mirroring with exact source samples and undo, plus a live symmetric brush: Mirror X/Z repeats every terrain, color and tile dab on the opposite half in one stroke and one undo record. Live-symmetric paths and objects remain separate. |
| Shape | VRV smooth/rough/relief with grain, softness, contrast, preserve symmetry | IMPLEMENTED cursor-anchored slope planes with world grades, preview and undo, regional/whole-map VRV Smooth (3-pass separable box blur with strength/grain), Rough +/- (multi-octave quintic lattice noise with grain, softness, contrast, deterministic seed and X/Z/XZ symmetry fold) and Relief +/- (`app/core/vrv_shapes.gd`, exposed in `Shape Terrain` via `terrain_commands.gd`), plus the Advanced Slope Studio: exact-angle ramps (`h = start + distance × tan(angle)` in world metres on the native 2 m grid), flat/rounded/soft/terrace/cliff/plateau profile ramps, berm/ridge/valley/trench/excavation stamps, per-shape lateral core/falloff blending, height and existing-slope masks, batch linear rows, radial fans and mirror X/Z with a configurable symmetry origin, all through one preview/apply flow that commits as a single undo step. |
| Paths | Original path CFG, VRV `EditorPathHost.cpp` and `EditorPath.h` | IMPLEMENTED rename and type changes, drag/edit/append/remove/reorder points, whole-path creation/removal for verified binary tables, plus Mission & Path Studio (`app/core/mission_profiles.gd`, `app/tools/mission_studio.gd`) decoupled by `(ModProfile, MissionProfile)` (`stock`, `vsr`, `vrv`, `custom:*`): Blank/Strategy/Instant/MPI/Duel/Lua/Custom profiles with DLL scope notes, mod-filtered preset browser, `edge_path` proposal, multi-path 2D/3D selection, atomic translate/rotate/mirror/clone/resample/2 m grid snap, collision-checked batch swaps and duplicate-name, missing-spawn and team-consistency checks directly on the native AiPath stream. Dynamic AI behavior requires a map-specific playtest. |
| Objects and mission | Original object CFG, VRV object/preset generators | IMPLEMENTED native BZN position and orientation editing, Object Label editing and static model preview. Both views support selection, drag, grid snapping and cancel. `[` / `]` rotate ±15° (Shift 1°), Ctrl+D duplicates the selection into the record stream before `groupTargets` with a fresh sequence, label and unique `kind=8` pointer ID, and Delete removes unreferenced placements (including clean 0-object / 0-path handling). All share undo, BZMAG save and re-import-verified native export; a counted edit rolls back to a byte-identical BZN. Target Profile & Mod Manager (`app/tools/target_profile_dialog.gd`, `app/core/mod_registry.gd`) and Stock-first New Map Wizard (`app/tools/new_map_wizard.gd`) decouple Stock/VSR/VRV/Workshop profiles with non-destructive switching and dry-run conversion analysis. Transform edits, template-cloned insertions and unreferenced removals carry 2.0.185 MISSION / RUN evidence; insertion of classes not yet present in the map remains pending. |
| Sounds | VRV `SoundPoints.h`, `SoundPointsHost.cpp`, `vrv_sndpoint.odf` | IMPLEMENTED structured Sound Point editor (`app/tools/sound_editor.gd`) strictly gated to `vrv_sndpoint` objects (ordinary labels stay in Object Label editor), `vrvsnd:` parser/formatter/clamping (`volume`, `range`, `interval`, `jitter`, `pitch`, `near`), sound filename validation and local/game audio scan, atomic Duplicate Sound Point (single undo step from selected template), Undo/Redo, BZMAG save/reopen and native BZN export/re-import. Placing `vrv_sndpoint` from scratch without an in-map template and runtime playback (VRV client only) remain pending. |
| Layers and nodes | BZMAP extension | IMPLEMENTED up to eight ordered layers, enable/opacity, typed height/delta/RGB/tile ports, channel previews, one undoable bake and a project round-trip. |
| UI theme | Wintage Golden Default, Vintage Dark, Vintage Classic, Nord, 21 tokens | IMPLEMENTED Wintage theme registry (`goldendefault`, `vintagedark`, `vintageclassic`, `nord`), Windows Verdana without AA, compact toolbar spacing toggle, `[ui]` `ConfigFile` persistence and live toolbar command filter (`tool_search`). Shortcut remapping pending. |
